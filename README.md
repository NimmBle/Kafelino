# Kafelino ☕✨

A modern coffee shop web application that allows users to browse products, explore categories, and interact with a stylish café-style interface. Kafelino aims to provide a smooth digital experience similar to ordering or exploring items in a real café.

---

## ✨ Features

- ☕ Browse coffee products and menu items
- 🗂️ Category-based navigation
- 🔎 Clean and modern UI
- 📱 Responsive design (desktop & mobile)
- ⚡ Fast loading with client-side rendering
- 🛒 Foundation for e-commerce functionality
